Open source · self-hosted

Alfred is the teammate you mention in Slack when work needs a tool, not a chat window.

Install it once. Connect Slack, git, JIRA, and the rest of your stack. Config and secrets stay in .alfred/ on your machine or VPC — not a SaaS.

Getting started Architecture notes

What it does

Tickets where the team already works

Create and update Slack List tasks or JIRA issues from a thread. Uses the thread as the ticket body. Defaults new JIRA issues to type Task.

Code and PRs

Mirrors repos, greps and reads files, reviews PRs, and can open a draft PR on an isolated branch when write mode is on.

Docs, not guesses

Answers from an indexed handbook/runbook. Cites a public docs URL when you configure one. Optional web search when the index has nothing.

Ops data

Read-only Athena and CloudWatch. Google Sheets and Docs. Recurring cron jobs that post back to Slack.

Inbound work

Connectors such as Periskope (WhatsApp) can pull chats and tickets onto a Slack List or JIRA — one destination, not both.

Decks and scripts

HTML slide decks at a stable share URL. Company script packages from a git repo, run on a schedule or via chat.

How a request is handled

  • You @alfred in a Slack channel thread (not the app DM window).
  • Alfred loads that thread, classifies the job, and picks tools (JIRA, Slack List, git, docs, AWS, …).
  • Writes that change JIRA or git can require confirmation, depending on governance settings.
  • Replies stay grounded in tool results — it should not invent ticket keys or file paths.

What it is not

  • Not a hosted multi-tenant SaaS. You run it (laptop, EC2, or Docker).
  • Not Slack DMs — channels only.
  • Not MCP or generic OpenAPI connectors yet (planned as v3).
  • Not a replacement for your ticketing UI — it creates and updates work from conversation.

Getting started

Python 3.13 locally (or Docker). Full operator guide is README.md in the repository.

  1. git clone <repo-url> alfred && cd alfred
  2. ./scripts/setup.sh then ./scripts/up.sh
  3. Open http://127.0.0.1:5173 and log in with alfred token
  4. Admin → Secrets: Slack bot/app tokens + an LLM API key
  5. Admin → AI: route investigation to a capable model
  6. /invite @alfred in a channel, then @alfred hello

Alfred answers in channels only — not the Slack app DM window.
